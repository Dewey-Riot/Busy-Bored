❓ Busy Bored Help & Documentation

QUICK START

• New Cards & Shortcuts: Click "+ New Card" in header or press N / C on keyboard.

• List Drag Handle: Reorder columns using the grip handle (⋮⋮) in list headers.

• Floating Pins: Click "📌 Pin Window" in any card to spawn an independent, fully interactive reference window.

APPLE INTEGRATIONS

• Bear: One-way export via bear://x-callback-url/create.

• Fantastical: Natural-language parsing via x-fantastical3://parse?sentence=....

• Reminders: Sends the current card to the "Busy Bored to Reminders" Apple Shortcut.

DATABASE / BACKUPS

• IndexedDB: Durable local structured storage for cards, lists, settings, and image blobs.

AI COPILOT

• Secure Architecture: Proxies requests via server-side endpoint. Client app state stores no API keys.

INSTALL APP

• iOS / macOS: Add to Home Screen or Dock via browser menu.
